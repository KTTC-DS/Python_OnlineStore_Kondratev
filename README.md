# 🛍️ Интернет-магазин «Торты | Бенто | Капкейки Саратов»

Проект интернет-магазина для продажи тортов, капкейков и бенто-тортов.  
Реализована полная функциональность: каталог товаров, корзина, оформление заказов, 
история заказов, личный кабинет, админ-панель.

---

## ⚙️ Установка и запуск

### 🐳 Через Docker (рекомендуемый способ)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/KTTC-DS/Python_OnlineStore_Kondratev-LP.git
   cd Python_OnlineStore_Kondratev-LP

2. **Запустите контейнеры:**

    ```bash
    docker-compose up --build

3. **Приложение станет доступно по адресу:**
    ```
    http://localhost:8000

4. **Создайте суперпользователя (для входа в админку):**

    ```bash
    docker-compose exec web python manage.py createsuperuser
    Админ-панель: http://localhost:8000/admin

5. **Админ-панель:**
    ```bash
    http://localhost:8000/admin

### 💻 Локальный запуск (без Docker)

1. **Создайте и активируйте виртуальное окружение:**

    ```bash
    python -m venv venv
    source venv/bin/activate  # Linux/macOS
    venv\Scripts\activate      # Windows
    ```

2. **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
   
3. **Настройте базу данных PostgreSQL
(создайте БД и укажите параметры в online_store/settings.py 
или через переменные окружения).**


4. **Выполните миграции:**
    ```bash
    python manage.py migrate
 
5. **Запустите сервер:**
    ```bash
    python manage.py runserver

### 🧪 Тестирование
Все тесты находятся в папке ```users/tests/```

1. **Запуск тестов через Docker:**
    ```bash
    docker-compose exec web python manage.py test users

2. **Запуск всех тестов (локально):**
    ```bash
    python manage.py test

Результат: все тесты (модели, сигналы, бизнес-логика) должны проходить успешно.


### 🗂️ Основные возможности
✅ Регистрация, вход, выход из аккаунта\
✅ Каталог товаров с карточками (название, описание, цена, изображение)\
✅ Добавление товаров в корзину (с выбором количества)\
✅ Управление корзиной (изменение количества, удаление позиций, полная очистка)\
✅ Оформление заказа с вводом контактных данных\
✅ История заказов с детальным просмотром состава\
✅ Админ-панель для управления товарами, категориями, заказами, клиентами\
✅ Полностью на русском языке (включая статусы заказов)\
✅ Docker-контейнеризация (база данных и веб-приложение)\
